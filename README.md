# JavaScript Course — Classes & Exercises (freeCodeCamp)

This repository contains my **learning code** from the freeCodeCamp JavaScript curriculum.

This is where I push everything I do while working through the course — lessons, exercises, labs. Most of it isn't polished and isn't meant to be. But a lot of it is real logic I'll reuse in actual tools later: a few of these exercises are already the starting point for things I'm building. The idea is to share and make my progress visible, without worrying about the finished versions.

## What's in here
- Code examples and practice code from lessons
- Workshop and lab solutions (certification projects excluded)
- Experiments while learning

## What this isn't
- Polished or production-ready code
- A portfolio — finished projects live in [javascript-course-projects](https://github.com/miguel1715/javascript-course-projects)

## Status
- In progress, updated as I work through the course
